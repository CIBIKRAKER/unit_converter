# Flask Unit Converter

A simple web application built with **Flask** to convert **length**, **weight**, and **temperature** units.

## Features

* **Length Conversion:** Meter, Kilometer, Mile, Inch
* **Weight Conversion:** Gram, Kilogram, Pound, Ounce
* **Temperature Conversion:** Celsius, Fahrenheit, Kelvin
* User-friendly web interface with navigation
* Input validation and error handling
* Displays conversion results neatly

---

## Requirements

* Python 3.x
* Flask

---

## Installation

1.  **Clone the repository** or copy the project files:

    ```bash
    git clone <repository_url>
    cd <repository_folder>
    ```

2.  (Optional) Create and activate a virtual environment:

    ```bash
    python3 -m venv venv
    source venv/bin/activate    # Windows: venv\Scripts\activate
    ```

3.  Install **Flask**:

    ```bash
    pip install Flask
    ```

---

## Running the Application

1.  Run the main application file:

    ```bash
    python app.py
    ```

2.  Open your web browser and go to:

    ```text
    [http://127.0.0.1:5000](http://127.0.0.1:5000)
    ```

---

## Usage

1.  Navigate between **Length**, **Weight**, or **Temperature** converters using the navigation menu.
2.  Enter the **value** to convert.
3.  Select the **From** and **To** units.
4.  Click **Convert** to view the result.
5.  Use **Perform Another Conversion** to go back.
